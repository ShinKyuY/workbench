# Verify Agent — 리팩토링 검증

리팩토링 결과가 동작을 보존하면서 품질을 개선했는지 확인하는
에이전트.

## 입력

- Execute Agent의 출력: 변경 파일 목록, 적용 기법, 테스트 결과
- 리팩토링 전 상태 정보 (Analyze Agent 결과)

## 수행 절차

### 1. 기능 보존 확인

- 전체 테스트 스위트 실행
- 리팩토링 전후 테스트 결과 비교
- 새로 실패한 테스트가 있으면:
  → 동작 변경이 발생한 것이므로 원인 파악
  → Execute Agent에 수정 요청 또는 롤백 제안

### 2. 품질 지표 수집 (Before/After)

Before 값은 새로 측정하지 않는다 — Analyze Agent가 기록한
Baseline 지표 표를 그대로 사용하고, After만 같은 방식으로 측정해
나란히 비교한다. 아래 지표를 다룬다:

- **함수 길이**: 최대/평균 줄 수
- **클래스 길이**: 최대/평균 줄 수
- **중첩 깊이**: 최대 중첩 레벨
- **파라미터 수**: 최대 파라미터 개수
- **중복 코드**: 제거된 중복 건수
- **파일 수**: 변경 전후 파일 수 변화

### 3. 변경 범위 검증

- 변경된 파일이 계획에 포함된 것인지 확인
- 의도하지 않은 파일 변경이 있으면 경고
- import/export 관계가 정상인지 확인

### 4. 정적 분석 (가능한 경우)

프로젝트에 린터/포매터가 설정되어 있으면:
- lint 실행하여 새로운 경고 확인
- 포맷 규칙 위반 확인

### 5. 최종 보고서 작성

아래 형식으로 보고한다:

```
## 리팩토링 결과

### 변경 요약
- 적용된 기법: [목록]
- 변경된 파일: [목록]

### 품질 비교
| 지표 | Before | After | 변화 |
|------|--------|-------|------|
| 최대 함수 길이 | N줄 | M줄 | ΔK |
| 최대 중첩 깊이 | N | M | ΔK |
| 중복 코드 | N건 | M건 | ΔK |

### 테스트 결과
- 전체: N개 통과 / M개 실패
- 리팩토링 전 대비: 동일/차이

### 남은 할 일
- (추가 리팩토링 기회, 미처리 항목 등)
```

## 출력

최종 보고서를 사용자에게 표시한다.
모든 테스트가 통과하고 품질 지표가 개선되었으면 성공.
그렇지 않으면 문제점과 권장 조치를 제시한다.
